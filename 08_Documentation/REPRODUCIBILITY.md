# Executed revision: reproducibility and interpretation

## Authoritative outputs

The executed revised modeling implementation is Python 3.12.14. The shipped `requirements.txt` pins the numerical libraries used. All eight empirical article figures were generated by executing `Plot_Article_ggplot2.R` with R 4.3.3 and ggplot2 3.4.4. Original R modeling scripts are preserved as historical source. `RUN_FROM_R.R` is an optional unexecuted convenience launcher for the Python backend; the separate R plotting script has been executed and verified.

`03_Results/execution_manifest.json` records the actual core source hashes, data hashes, library versions, platform, seeds and protocol. `package_manifest.json` adds hashes for all distributed files. Source CSV rows have stable **1-based** `row_id`; they are not policy numbers. Fractions are 0–1, not percentages unless explicitly formatted.

The included runs cover seeds 1234–1243 on both datasets. There are 80 complete trained trajectories: 2 datasets × 10 seeds × (three main architectures + strict Multilayer). Static Multilayer and the conditional comparators are recorded within the main trajectories. Each trajectory fits the eight learners after D1, D2 and D3; D4 never contributes training labels to an evaluated model.

## Data and label access

Carclaims: 15,420 rows, 32 raw predictors, 923 frauds. Insurance Claims: 1,000 rows, 38 raw predictors, 247 frauds. Nominal split fractions are 50/30/10/10%, with class-stratified random splitting. Using labels for stratification is a retrospective evaluation design, not an online chronological experiment.

Only D1 predictors fit feature selection, numeric medians/scales, categorical modes/one-hot levels. Explicit IDs and incident addresses are dropped; `?` is missing. Two date fields are deterministically expanded. The code records selected/dropped features per seed. D1 screening is unsupervised; it uses its features transductively. The same fitted encoder is used in later batches.

All alerted records plus `ceil(0.1 × non-alert count)` random non-alerts are reviewed. A stored outcome becomes an available training label only after this selection. No unreviewed record is automatically assigned class 0. The audit uses a seeded random draw independent of outcomes. Stored full outcomes are used separately for retrospective evaluation.

D1 anomaly metrics are descriptive training-initialization diagnostics. Primary article metrics pool predictions from D2–D4. D2 has 60% of that pooled evaluation population. Every later partition is predicted before its labels are used to update a subsequent model. D4 review counts are hypothetical final-batch workload and never train an evaluated prediction.

## Architecture, ablation and comparators

Main `(T_AD,T_ML)=(3,4)`; strict Multilayer `(5,6)`. Simple-A uses 9 votes. Simple-B adds a full-D1 entropy top-20% vote. Multilayer recomputes entropy on the consensus candidates and keeps their top 20%. Top fractions use a deterministic numerical top-k procedure in the locked environment; ties can be representation-dependent. The same integer anomaly threshold represents a different vote fraction with ten versus nine voters.

Multilayer-static uses exactly the same initial reviewed data, SMOTE and fitted models as updating Multilayer. Its later review masks are workload accounting only. No later records update its models. This is a complete-policy update ablation; it does not hold later acquisition constant.

Individual LR/SVM/XGB/NB/RF/KNN/AdaBoost/ANN predictions come from the Simple-B training trajectory. BalancedRF and PSO-XGB-adapted are trained on those same verified records. Therefore the comparator table conditions on Simple-B acquisition. Comparator-specific `review_rate` fields represent the hypothetical review workload of their predictions; they do not describe which labels trained them. Their training follows the Simple-B masks saved in the same file.

BalancedRF has 200 trees, leaf size 2, within-tree balancing, replacement and no preceding SMOTE. PSO uses four particles, three iterations, inertia .7, attraction 1.4/1.4. Parameter bounds and decoding are explicit in `Comparators.py`. Verified-D1 three-fold AP selects one configuration; fold-only SMOTE avoids outcome leakage into validation resampling. The shared unsupervised encoder was fitted on D1 features; no D2–D4 observations enter this inner search. Later batches refit with the chosen parameters. The modest search is adapted from the PSO-XGBoost concept in Ding et al.; it is **not an exact reproduction** of their paper or all its interpretability analyses.

## Metrics and numerical serialization

Fraud=1. Counts TP/FP/TN/FN, precision, recall, F1, specificity, balanced accuracy, accuracy, ROC-AUC, AP, alert and total review rates are retained. Mean probabilities rank records; ≥4 or ≥6 hard positive votes define the ensemble alert. Oversampling means these probabilities should not be treated as calibrated population risks.

`pr_auc` is **average precision** with score ties grouped at thresholds, not trapezoidal PR-AUC. `metrics_by_seed.csv` has one row per dataset/seed/setting/architecture/partition. `summary_mean_sd.csv` computes sample SD (ddof=1) across the ten seeds. Repeated splits reuse observations; SD is not a confidence interval for independent populations.

The original prediction writer exports scores with 16 significant digits. Floating-point ties can slightly change upon reading CSV. `reconcile_exported_scores.py` recomputes ROC-AUC and AP from the **distributed CSV score representation** before aggregation. In-memory metrics remain in `metrics_before_csv_roundtrip.csv`; `score_serialization_audit.csv` records the small differences. Count-based metrics and predictions do not change. `verify_results.py` independently calculates confusion metrics, rank-based ROC-AUC and threshold-grouped AP from these files. Parallel forest reductions can differ by machine epsilon; the identical-initial-model check uses a 1e-14 probability tolerance and exact hard-label equality.

## Limits of the delivered evidence

These are public-benchmark retrospective simulations using recorded labels as perfect expert feedback. Secondary dataset hosting references do not establish collecting insurer, licensing authority, or real/synthetic field provenance. Different schemas prevent direct transport of one fitted model; models are retrained under the same workflow. The data had been examined previously; settings are fixed illustrative choices, not a preregistered optimum on an untouched external test population.

The results do not establish universal dominance, temporal robustness, equal-budget causal benefit from entropy, actual investigation cost savings, or full reproduction of graph/deep-learning comparators. The paper, response and Persian report retain these boundaries. Original code/output discrepancies are documented rather than concealed. No new result was invented to satisfy a reviewer request.
