# ریوایز در قالب نسخه پنجم مقاله ارسالی

**اصلاحات در همان مقاله اولیه اعمال شده‌اند.** اندازه صفحه، حاشیه‌ها، سربرگ،
سبک ارجاع، پنج بخش اصلی، ترتیب روش‌شناسی و سه الگوریتم حفظ شده‌اند.
تصاویر ساختاری ۱ و ۲ عین فایل‌های نسخه پنجم هستند و بازطراحی نشده‌اند.
توضیح کنار تصاویر، تفاوت میان نمایش مفهومی قدیمی و جزئیات اجرای اصلاح‌شده را روشن می‌کند.

مدل‌ها و نتایج معتبر Python همان بسته قبلی‌اند؛ در این مرحله مدل تازه‌ای آموزش
داده نشده است. هشت نمودار تجربی واقعاً با R و ggplot2 اجرا و از همان خروجی‌ها
رسم شده‌اند. سبک خاکستری، پنل‌ها، رنگ، نوع خط و علامت نقطه با مقاله اولیه هماهنگ است.
دیتاست دوم نیز با همین اسکریپت رسم می‌شود. اعداد یا شبکه آستانه‌های اجرا‌نشده ساخته نشده‌اند.

## بازسازی

Python 3.12 و R نصب باشند. در ریشه پوشه استخراج‌شده:

```bash
python -m pip install -r requirements.txt
Rscript 01_Code/Install_Plot_Packages.R
python RUN_ALL.py --rebuild-only --pdf
```

برای ساخت PDF به pdfLaTeX، BibTeX و XeLaTeX نیاز است؛ بدون `--pdf` نمودارها و
خروجی‌های عددی بازسازی می‌شوند. محیط رسم تحویلی R 4.3.3 و ggplot2 3.4.4 بوده است.
نسخه تمام وابستگی‌های R در گزارش محیط ثبت شده است.

برای آموزش مجدد همه آزمایش‌ها:

```bash
python RUN_ALL.py --rerun --pdf
```

خروجی جدید در `03_Results_reproduced` ذخیره می‌شود. دستور رسم مستقل:

```bash
Rscript 01_Code/Plot_Article_ggplot2.R
python 01_Code/verify_ggplot_outputs.py
```

اسکریپت کنترل، میانگین و انحراف معیارهای R را با خروجی Python تطبیق می‌دهد و
یکسان‌بودن دو تصویر ساختاری با فایل اصلی را کنترل می‌کند. مدل‌سازی به Python
انجام شده و تنها رسم نهایی به R منتقل شده است؛ کدهای R اصلی پایان‌نامه در آرشیو محفوظ‌اند.

## تفسیر درست

منابع مقاله ۴۰ مورد، شامل سه مقاله مرتبط از مجله مقصد است. بهترین امتیاز همه
مقایسه‌ها لزوماً متعلق به SAD نیست و متن این واقعیت را حفظ می‌کند. منشأ بیمه‌گر
دیتاست دوم هنوز مستند نشده و این محدودیت صریحاً بیان شده است.

استفاده از ChatGPT برای کمک به کد، نمودار و متن در مقاله اعلام شده است. تأیید
تفسیر علمی و نسخه نهایی بر عهده نویسندگان است. نسخه نشان‌دار و نقشه تغییرات،
اصلاحات واقعی را روشن می‌کنند؛ حفظ ظاهر به معنی حذف گزارش اصلاحات نیست.

## ویرایش نهایی

منبع داده دوم، صفحه Insurance Claims متعلق به mexwell در Kaggle است که شما
معرفی کرده‌اید؛ نشانی آن در متن و مراجع ثبت شده است. نام نویسندگان حفظ شده و
نسخه بدون نام ساخته نشده است. طبق درخواست نهایی شما، لینک مخزن عمومی
[گیت‌هاب پژوهش](https://github.com/Mehrab-Atighi/Anomaly-Detection-Algorithm-for-Enhanced-Fraud-Identification-in-the-Insurance-Sector) در بخش ۴٫۶ مقاله و پاسخ داور درج شده است؛ کدها، داده‌ها، خروجی‌ها و فایل‌های بازتولید مقاله در این مخزن معرفی شده‌اند.

گزارش مشابهت‌یابی ارسالی و توضیح ویرایش پایانی در پوشه مستندات قرار دارند.
عدد ۱۴٪ مربوط به نسخه بررسی‌شده در همان گزارش است؛ درصد نسخه ویرایش‌شده
اندازه‌گیری نشده است. ویرایش مستقیم انگلیسی انجام شده ولی سرویس Grammarly
اجرا نشده است. خوانایی نمودارها و صفحه‌آرایی بهتر شده و داده، کد مدل‌ها و
نتایج عددی اجراشده تغییری نکرده‌اند.
